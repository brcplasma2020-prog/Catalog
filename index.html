CAD File Preparation & Spline Conversion

To guarantee accurate quotes and clean CNC plasma/laser toolpaths, drawings must contain continuous 2D polylines. Follow the simple steps below for your preferred CAD tool to convert SPLINE entities.

CAD

AutoCAD / DraftSight

  1. Type command PEDIT and press Enter.
  2. Select the SPLINE object.
  3. When asked, choose Convert to Polyline.
  4. Set precision precision (default 10 is standard).
  5. Alternatively, use FLATTEN command.
INK

Inkscape (Vector Editor)

  1. Select all vector paths (Ctrl + A).
  2. Go to top menu: Path ➔ Object to Path.
  3. Select all nodes using the Edit Paths Tool.
  4. Click Make selected segments lines.
  5. Export as Desktop Cutting DXF R14.
LC

LibreCAD / QCAD

  1. Select the spline geometry.
  2. Choose Modify ➔ Explode.
  3. Use Create Polyline from Existing Segments.
  4. Save File as AutoCAD 2004 DXF format.
